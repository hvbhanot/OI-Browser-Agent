OpenWebUI Sidekick

Configure the OpenWebUI instance the side panel loads.

e.g. http://localhost:3000 or https://openwebui.example.com
Match pattern for content scripts. Usually your URL with /* appended, e.g. http://localhost:3000/*
Screenshots & page text: Use the floating buttons in the side panel — 📄 inserts the current page text as a file, 📸 captures the visible tab and pastes the screenshot into chat. Enable "Paste Large Text as File" in OpenWebUI Settings → Interface for text insertion to work. You can also use the keyboard shortcut Ctrl/⌘+Shift+Y or the right-click menu for screenshots.
